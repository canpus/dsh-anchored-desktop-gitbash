# 省钱模式预设（economy）独立包

> 本包随「DeepSeek Harness 桌面版」主程序每次发布同步更新（省钱模式 = 主程序的同款实现）。

## 这是什么

**省钱模式（preset ID: `economy`）**：官方 Standard 预设 + 子 Agent 默认路由注入——普通子 Agent、分支子 Agent、嵌套子 Agent 默认使用你选定的便宜模型（默认 `deepseek-v4-flash`），主 Agent 仍是你的主力模型（如 Pro）。适合"主 Agent 用贵模型、子 Agent 用便宜模型"的降本用法。

本包给你两个选择：

- **完整版**：直接用桌面版绿色包（内置省钱模式 + 锚定/路由实验开关 + 全套壳功能）；
- **只用预设**：把本包生成的 `economy` 预设装进你自己的 dsh（官方 CLI/Web 或任何兼容 GUI），配合你喜欢的壳使用。

## 安装

需要：官方 DeepSeek Harness 已安装（本包内含的 Standard 快照出处见 `economy-standard/NOTICE`，与该版本引擎匹配最佳）。

```
node install-economy-preset.cjs [providerId] [modelId]
```

- 不带参数：交互询问（回车 = 默认值 `deepseek` / `deepseek-v4-flash`）；
- 生成位置：`~/.dsh/.agent-presets/economy/`（重复运行幂等覆盖）；
- 装好后在你的 dsh / GUI 里把**默认预设**切换为 `economy`（显示名「省钱模式」）。

## 必须知道的边界（诚实声明）

- **Workflow/Ralph 不受省钱约束**：官方 Workflow 未显式指定模型时、以及当前内置 Ralph，其 worker 默认继承主 Agent 路由，可能按主模型计费。本预设不改官方工具行为。
- **provider/model 是完整 pair**：安装器强制写入"服务商 + 型号"双字段；两者之一缺失即报错，绝不静默降级（降级 = 子 Agent 悄悄用回主 Agent 的 Pro）。
- 省钱模式**不含任何思维链锚定逻辑**：它就是官方 Standard + 子模型路由。锚定/路由实验另由主程序标题栏的互斥开关提供（效果不保证，问题归上游）。

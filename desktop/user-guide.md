# DeepSeek Harness 桌面版 · 用户指南

> 版本随包更新（当前 v0.4.2）。最简用法：解压 → 双击「启动.bat」→ 在应用内填 API Key → 打开「省钱模式」开始干活。
> 本文重点在第 2、3 节——**「省钱模式」**（子 Agent 用便宜模型）与**实验开关**（锚定/路由）。

---

## 1. 快速开始

1. **解压**到任意目录（建议不含中文/空格的路径，如 `D:\DeepSeekHarness`）；
2. 双击 **`启动.bat`**，几秒内打开窗口（官方后端随包内置，**无需联网、无需预装 Node、无需管理员权限**）；
3. 首次运行会自动创建数据目录 `%USERPROFILE%\.dsh`（会话、设置、预设都在这里）；
4. 在应用内「设置」中填写你的 **DeepSeek API Key**（或点击左上方模型名旁的下拉进入模型设置）——Key 只存本机，绝不随包分发；
5. 打开「省钱模式」（见下节），新建对话开始使用。

**卸载**：删除整个文件夹即可（零残留、不写注册表）。注意 `%USERPROFILE%\.dsh` 会保留你的会话与设置，想彻底清空可手动删除该目录。

---

## 2. 开启「省钱模式」（重点）

主 Agent 用贵模型、**子 Agent 默认用你指定的便宜模型**——这是本桌面版的核心降本功能（DeepSeek 涨价后的钱包保护）。

### 2.1 是什么

「省钱模式」（内部预设名 `economy`）= **官方「标准模式」原样** + 一条子模型规则：

| 对象 | 模型 |
|---|---|
| 主 Agent | 你的主力模型（如 V4-Pro），不受影响 |
| 普通子 Agent / 分支子 Agent / 嵌套子 Agent | 你选定的便宜模型（默认 **deepseek-v4-flash**） |

- **不含任何思维链锚定逻辑**——它就是官方标准模式 + 子模型路由，行为可预期；
- 服务商 + 型号是**成对保存**的（同名的模型不会串到错误的服务商）；
- 若所选模型已不在目录中，界面会**强制要求重新选择**，绝不会悄悄让子 Agent 用回 Pro。

### 2.2 怎么开（三步）

1. 点击窗口**标题栏的「模式切换」**按钮；
2. 打开 **「省钱模式」** 开关；
3. 在下拉里选择服务商与子 Agent 模型（默认推荐 **deepseek-v4-flash**——便宜，干子任务足够）；
4. 点「应用」→ 确认重启后端（约半分钟）→ **新建一个对话**即生效。

> 提示：模式切换只对**新建会话**与**空白会话**生效，旧的非空会话保留创建时的模式。

### 2.3 必须知道的边界（诚实声明）

- **Workflow / Ralph 不受省钱约束**：官方 Workflow 未显式指定模型时、以及当前内置 Ralph，其 worker 默认继承主 Agent 路由，**可能按主模型计费**。界面启用省钱模式时会显示这条告警。
- 旧版「自定义子模型」（fc-child，融合锚定实验）已停止维护：旧会话仍可恢复，新对话请用「省钱模式」。

## 3. 实验开关：锚定 / 路由（可选，非默认）

标题栏上的 **「锚定」** 和 **「路由」** 是两个互斥开关（开一个自动关另一个），对应两种第三方「思维链」实验预设：

| 开关 | 对应预设 | 效果 |
|---|---|---|
| 锚定 | anchored-standard | 首轮极简锚定 → 工具调用后开放全量工具（We need 风格思维链的社区尝试） |
| 路由 | router-standard | 任务感知 react/spec/weak 三模式路由 |

**定位：无情的搬运机器。** 这两个预设逐字搬运自上游仓库（版本锁定、随发行包显示出处），本项目**不保证思维链效果**——是否稳定出现 We need、是否提升任务质量，归上游；我们只保证：文件搬全、装得上、开关互斥、不影响旧会话。

- 锚定预设需要本机装有 **Git for Windows**（安装时自动探测，探测不到会拒绝开启）；
- 关闭开关 → 回落到你在「模式切换」里选的基础模式（官方模式或省钱模式）；
- 实验预设只影响**新对话与空白会话**，非空旧对话不热切。

## 4. 日常功能速查

| 功能 | 用法 |
|---|---|
| **中文命令** | 输入框直接打 `/压缩` `/目标` `/计划` `/权限` `/导出` `/模型`（提交时自动翻译为官方英文命令） |
| **消息右键** | 「重发此消息」「从此处分支」（任意一条用户消息上右键）；选中文字右键可「引用」到输入框 |
| **导出对话 PDF** | 标题栏「导出对话」→ 默认列出**当前工作区现存会话**；勾选「包含历史对话（已归档）」才显示归档会话 |
| **拖文件进对话** | 拖任意文件进窗口 → 自动复制到会话临时区并把「文件名+路径」注入输入框，按回车发给模型（模型可读该路径）；**图片仍走官方附件流程** |
| **字体缩放** | Ctrl+滚轮 / Ctrl+= / Ctrl+- / Ctrl+0，或标题栏 A− / A+ 按钮；自动记忆 |
| **代理设置** | 标题栏「代理设置」→ http/https 分填（检查更新/升级即时生效，后端重启生效）；直连不稳时必填 |
| **检查更新** | 标题栏「检查更新」→ **五路**检测：本应用 Release / 官方后端 / 锚定模板 / 路由 / GitBash 执行器 |
| **托盘** | 右键托盘图标：模式切换/导出/代理/检查更新/重启/退出 |

## 5. 成本建议

- **主对话**用 V4-Pro（质量）；**子 Agent** 默认 Flash——父模型每次派活都会把历史同步给子 Agent，全用 Pro 会成倍烧钱；
- 省钱模式覆盖普通/分支/嵌套子 Agent；**Workflow/Ralph 的 worker 不受约束**（见 §2.3），不常用可无视；
- 长会话记得用 `/压缩` 控制上下文。

## 6. 常见问题

| 问题 | 解答 |
|---|---|
| 首次启动慢吗？ | 官方后端随包内置，首启几秒即开（无需重建依赖） |
| SmartScreen 提示？ | electron 为官方签名二进制，zip 本身未签名——选「仍要运行」 |
| 检查更新超时/失败？ | 标题栏「代理设置」填入你的代理（http/https 分填）再试 |
| 锚定开关开不了？ | 本机未找到 Git for Windows——安装后重试（这是上游预设的硬要求） |
| 旧版「自定义子模型」会话还在？ | 正常：旧会话按旧预设恢复；新对话请用「省钱模式」 |
| 模型回复里混入 thinking？ | 第三方模型（如 MiMo）的已知上游现象，官方模型无此问题 |

## 7. 行为宪法（AGENTS）

本软件随包提供便携版行为宪法 `portable-agents.md`：首次启动会写入 `%USERPROFILE%\.dsh\AGENTS.md`（若该文件已存在则**绝不覆盖**）。模型开始动手时会自动注入这份宪法——安全操作边界（不删用户文件、凭据保护、诚实汇报等）以此为基准。

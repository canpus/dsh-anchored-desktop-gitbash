# DeepSeek Harness 桌面版 · 用户指南

> 版本随包更新（当前 v0.3.8）。最简用法：解压 → 双击「启动.bat」→ 在应用内填 API Key → 打开「自定义子模型」模式开始干活。
> 本文重点在第 2 节——**如何开启「自定义子模型」**，这是本桌面版的灵魂功能。

---

## 1. 快速开始

1. **解压**到任意目录（建议不含中文/空格的路径，如 `D:\DeepSeekHarness`）；
2. 双击 **`启动.bat`**。首次启动约 1-5 分钟（重建依赖链接，纯本地操作，**无需联网、无需管理员权限**），之后秒开；
3. 首次运行会自动创建数据目录 `%USERPROFILE%\.dsh`（会话、设置、预设都在这里）；
4. 在应用内「设置」中填写你的 **DeepSeek API Key**（或点击左上方模型名旁的下拉进入模型设置）——Key 只存本机，绝不随包分发；
5. 打开「自定义子模型」模式（见下节），新建对话开始使用。

**卸载**：删除整个文件夹即可（零残留、不写注册表）。注意 `%USERPROFILE%\.dsh` 会保留你的会话与设置，想彻底清空可手动删除该目录。

---

## 2. 开启「自定义子模型」模式（重点）

这是本桌面版的核心：官方四种模式之外的**第五种模式**，实现了「**极简思维链锚定 → 工具调用后开放**」的融合行为。

### 2.1 是什么

| 阶段 | 行为 |
|---|---|
| **首轮（锚定）** | 系统提示 = 官方极简一句话；工具只有 **bash(GitBash) + str_replace_editor** 这对官方极简组合；**无输出封顶、无 AGENTS/skill 注入**——把模型钉在官方基准同款的最小表面，实测可稳定唤出 V4 Pro 的**新型思维链**（We need 风格开场） |
| **首个工具调用或首条回复后** | 自动开放**全量 Standard 工具**（subagent 全家、pwsh、web、todo、skill 等）+ **AGENTS.md 行为宪法恢复注入**（"动手即注入"安全结构） |
| **子 Agent** | 默认使用你指定的**子模型**（省成本），且子 Agent 同样继承锚定+全量行为 |

### 2.2 怎么开（三步）

1. 点击窗口**标题栏的「模式切换」**按钮；
2. 在模式列表中选择 **「自定义子模型」**；
3. 在「子 Agent 模型」下拉里选一个模型：
   - 默认推荐 **DeepSeek-V4-Flash**——便宜，干子任务足够（8-17 官方涨价后更应如此）；
   - 重要/困难任务可临时换 **V4-Pro**；
4. 点「应用」→ 确认重启后端（约半分钟）→ **新建一个对话**即生效。

> 提示：模式切换后只对**新建会话**生效，旧会话保留创建时的模式。想全部会话走新模式，用「设为默认」并新建对话。

### 2.3 首次体验建议（照做不踩坑）

1. 新建对话后，把会话沙箱切到 **「完全访问」**（在官方界面右上角权限设置里）——`bash` 经 Git-for-Windows 执行，MSYS 运行时在受限沙箱内起不来，这是 Windows 的硬限制，**本软件不绕过沙箱边界**；不切的话第一次跑 bash 会收到带指引的错误，按提示单次升级也可以；
2. 确保本机装有 **Git for Windows**（bash.exe 来源；本软件会自动探测安装位置，无需手动配置）；
3. 发一个任务，观察：首轮回复应带**新型思维链**风格；一旦模型调用工具（或完成首条回复），下一轮起 AGENTS + 全量工具全部在位。

### 2.4 故障排查

| 现象 | 原因/解法 |
|---|---|
| bash 报 `failed to start bash` | 未装 Git for Windows，或 Git 装在自定义目录——重启应用后本软件会重新探测并写入路径 |
| bash 报沙箱错误 | 会话沙箱不是「完全访问」——切换或按提示单次升级 |
| 首轮没有新思维链 | 确认当前会话用的是「自定义子模型」模式（旧会话可能锁定旧模式）；另注意新思维链是本模式的目标形态而非每个字都不同 |

## 3. 日常功能速查

| 功能 | 用法 |
|---|---|
| **中文命令** | 输入框直接打 `/压缩` `/目标` `/计划` `/权限` `/导出` `/模型`（提交时自动翻译为官方英文命令） |
| **消息右键** | 「重发此消息」「从此处分支」（任意一条用户消息上右键）；选中文字右键可「引用」到输入框 |
| **导出对话 PDF** | 标题栏「导出对话」→ 默认列出**当前工作区现存会话**；勾选「包含历史对话（已归档）」才显示归档会话 |
| **拖文件进对话** | 拖任意文件进窗口 → 自动复制到会话临时区并把「文件名+路径」注入输入框，按回车发给模型（模型可读该路径）；**图片仍走官方附件流程** |
| **字体缩放** | Ctrl+滚轮 / Ctrl+= / Ctrl+- / Ctrl+0，或标题栏 A− / A+ 按钮；自动记忆 |
| **代理设置** | 标题栏「代理设置」→ http/https 分填（检查更新/升级即时生效，后端重启生效）；直连不稳时必填 |
| **检查更新** | 标题栏「检查更新」→ 四路检测：本应用 Release / 官方后端 / 锚定模板 / GitBash 执行器；官方后端有新版可一键自动升级（失败自动回滚） |
| **托盘** | 右键托盘图标：模式切换/导出/代理/检查更新/重启/退出 |

## 4. 成本建议

- **主对话**用 V4-Pro（质量与新型思维链）；**子 Agent** 默认 Flash——父模型每次派活都会把历史同步给子 Agent，全用 Pro 会成倍烧钱；
- 长会话记得用 `/压缩` 控制上下文；需要极致缓存命中的场景可换官方「极简」模式（仅 Linux/macOS/WSL；Windows 用本模式的锚定行为替代）。

## 5. 常见问题

| 问题 | 解答 |
|---|---|
| 首次启动为什么慢？ | 正在重建依赖链接（1-5 分钟），只此一次 |
| SmartScreen 提示？ | electron 为官方签名二进制，zip 本身未签名——选「仍要运行」 |
| 检查更新超时/失败？ | 标题栏「代理设置」填入你的代理（http/https 分填）再试 |
| 窗口关了后台还有进程？ | 此 bug 已修复（退出强制清理 + 5 秒保险丝）；若再现请反馈，日志可直接定位 |
| 模型回复里混入 thinking？ | 第三方模型（如 MiMo）的已知上游现象，官方模型无此问题 |

## 6. 行为宪法（AGENTS）

本软件随包提供便携版行为宪法 `portable-agents.md`：首次启动会写入 `%USERPROFILE%\.dsh\AGENTS.md`（若该文件已存在则**绝不覆盖**）。首轮锚定后、模型开始动手时会自动注入这份宪法——安全操作边界（不删用户文件、凭据保护、诚实汇报等）以此为基准。
